# Manufacturing Performance Analysis

## Project Overview

This project analyses manufacturing production and quality data to evaluate production target achievement, compare department performance, and identify areas for further operational investigation.

The project demonstrates a practical data analytics workflow, including data cleaning, transformation, analysis, and business interpretation.

## Business Objectives

- Measure production achievement against targets.
- Compare performance across departments and machines.
- Examine manufacturing defect rates.
- Investigate machine downtime and maintenance patterns.
- Support data-driven operational decisions.

## Tools and Technologies

- **Python:** Data cleaning and analysis using pandas.
- **SQLite:** SQL queries, joins, aggregations, and reporting.
- **Microsoft Excel:** Data analysis and reporting.
- **Power BI:** Production performance visualisation.

## Project Structure

- `data/` — Original and cleaned datasets.
- `excel/` — Excel analysis files.
- `sql/` — SQL queries and analysis.
- `python/` — Python notebooks.
- `powerbi/` — Power BI dashboard files.
- `images/` — Dashboard screenshots.
- `docs/` — Project documentation.

## Initial Findings

| Metric | Machining | Assembly |
|---|---:|---:|
| Production achievement | 94.18% | 91.76% |
| Defect rate | 1.80% | 2.43% |

In the analysed data, Machining achieved a higher percentage of its production target and recorded a lower defect rate than Assembly.

Assembly may be a useful priority for further investigation. Additional analysis is needed to establish the reasons behind these differences.

## Analytical Workflow

1. Inspect the datasets.
2. Clean and validate manufacturing records.
3. Combine related datasets.
4. Calculate production and quality metrics.
5. Compare department and machine performance.
6. Investigate downtime and maintenance patterns.
7. Present findings through visualisations and dashboards.

## Project Status

This project is being developed iteratively. Further analysis, dashboard improvements, and documentation will be added as the project progresses.
